# AI-Racer-2026: NICER GREEN MACHINES
A collabartion effort in participating in the Small-Scale Autonomous Racing Vehicle competition at UCF

## SOFTWARE

- Custom neural network using imitation learning to solve the problem of speeding up/ slowing down, drifting, pid control
- SLAM tool to visualize map from lidar
- Pathing techinque (obstacle avoidance) | works hand in hand with neural network
- Autoreversing to prevent car from crashing into wall. We don't get many chances to readjust so avoid hitting the wall all together.
